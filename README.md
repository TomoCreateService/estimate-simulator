# Web制作のお見積もりシミュレーター

TomoCreateService のWeb制作・LP制作・コーディング代行・Webアプリ開発の概算費用を、その場で確認できるReactアプリです。個人のお客様・制作会社様の相談前の目安として使用します。

## 使い方

1. 制作内容を選び、必要なオプション・数量・月次保守を指定します。
2. 内訳と初期費用・月額費用を確認します。表示は税込が初期状態で、税別に切り替えられます。初期費用と月額それぞれに、内税額または消費税額を表示します。
3. 必要に応じて宛名を入力し、「PDFで保存」を押します。ブラウザの印刷画面で用紙をA4、保存先を「PDFに保存」にしてください。ブラウザ側のヘッダー・フッターはオフにすると整った見た目になります。
4. 「この内容で相談する」から `https://tomo-cs.com/#contact` へ進みます。選択内容の自動送信は行わないため、相談時は保存した見積書を添えてください。

ホームページ制作にはTOP＋下層2ページ・デザインから公開・レスポンシブ対応・お問い合わせフォーム・基本SEOが含まれます。フォームは選択済みの状態で固定し、計算側でも追加料金から除外しています。LPのフォームは別料金です。

Webアプリ開発は100,000円〜（税別）の目安を表示し、「要相談」と明記します。コーディング代行はTOP・下層・LPの数量を組み合わせて指定できます。既存サイトへの追加は「オプションのみ」を選べます。

数量は0〜99の整数です。0・空欄は0件、負数・数値でない値は0件、小数は整数に切り下げ、99を超える値は99件として計算します。非表示のコーディング数量は集計しません。画面を再読み込みすると選択内容は初期状態に戻ります。

## ローカルで画面を確認する

Node.js 22.12以上の22系、または24系以降を使用してください。

```bash
npm ci
npm run dev
```

通常のURLは <http://127.0.0.1:5173/tools/estimate/> です。ポートが使用中の場合は、ターミナルに表示されるURLを開いてください。

## 単価の変え方

`src/config/prices.json` の `price` を税別の整数で変更してください。項目名・説明・「〜」の有無（`from`）・税率（`taxRatePercent`）も同ファイルで管理します。

- `services`：制作の基本料金
- `coding`：コーディング代行のページ単価
- `options`：オプション単価
- `maintenance`：月次保守の月額

税込は税別額に `(100 + taxRatePercent) / 100` を掛けて計算します。端数処理は円単位の四捨五入です。現在の全単価・数量0〜99では税込に端数が出ないことを自動テストで確認します。単価変更後に端数テストが失敗した場合は、価格または端数処理の方針を確認してください。

価格の変更はJSONだけで完結します。静的配信用のファイルへ反映するには、その後に `npm run build` で再ビルドしてください。新しい料金項目の追加は、必要に応じて選択UI・集計処理も変更します。

## テストの実行方法

```bash
npm test
npm run lint
npm run build
```

`npm test` はVitestによる27件のテストです。指定の正解表5件、フォームの二重請求防止、0・空欄・不正値の数量、月額分離、税込の端数、見積番号・30日後の有効期限などを確認します。単価を変更すると正解表のテストも変わるため、確認した期待値に更新してください。

ブラウザ確認を再実行する場合は、Google Chromeをインストールし、初回のみ以下を実行します。

```bash
npx playwright install firefox webkit
```

別のターミナルで開発サーバーを起動した状態で実行してください。

```bash
npm run test:browser
```

Chrome・Firefox・WebKitで、正解表に対応する画面操作、税込／税別切り替え、数量0・空欄、フォームの選択制御、印刷ボタン、印刷レイアウト、横はみ出し、コンソールエラー・警告を確認します。画面幅は1440・1280・1024・768・414・375pxです。WebKitはSafariと同系統のエンジンによる検証であり、Safari実機確認とは区別します。

テスト先を変更する場合は `TEST_URL` 環境変数を指定できます。

## ビルド・FTP配置

```bash
npm run build
```

生成された `dist/` の**中身**をWebサーバーの `/tools/estimate/` にFTPで配置します。Viteの `base` は `/tools/estimate/` に設定しています。PHP・Node.jsサーバー・データベースは不要です。

配信前のローカル確認は以下で行えます。

```bash
npm run preview
```

通常のURLは <http://127.0.0.1:4173/tools/estimate/> です。公開先を変更する場合は `vite.config.js` の `base` と `index.html` のcanonicalを変更してください。本番配置・GitHubへのpushはこの作業では行っていません。

## 構成と実装方針

- `src/config/prices.json`：税別単価と税率の一元管理
- `src/utils/calculateEstimate.js`：画面から分離した料金計算・数量の正規化・見積書情報生成
- `src/components/`：制作選択、オプション、概算結果、印刷用見積書
- `src/styles/`：SCSS・mFLOCSS・CSSの `@layer` によるスタイル
- `scripts/verify-browser.mjs`：ブラウザ確認とサンプル生成

見積番号は画面を開いた時点の日付＋ランダムIDで自動生成し、選択変更中は維持します。有効期限は発行日から30日後です。印刷用見積書には、宛名・日付・見積番号・有効期限・単価・数量・内訳・税別合計・消費税・税込合計・月額費用・概算の注記・屋号・URLを掲載します。

画面の色・書体は `~/tomo-cs-renewal/css/foundation/_variables.css` を参考にしています。元サイトのファイルは変更していません。ヘッダーは本体のロゴ・英文ナビ・900px以下のハンバーガーメニュー・スクロール時の縮小と背景変化を移植しています。各メニューは `https://tomo-cs.com/` の対応セクションへ移動します。

ロゴ画像は本体から `src/assets/TCSlogo.png` にコピーしました。英文書体は本体と同じ Cormorant Garamond のitalic 400です。Google Fonts配布のフォントを英文用に軽量化したWOFF2として同梱し、ライセンスは `src/assets/OFL-CormorantGaramond.txt` に保存しています。外部へのフォント・画像リクエストや計測スクリプトを使わず、静的ファイルで完結させています。
